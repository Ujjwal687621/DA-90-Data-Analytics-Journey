# 📝 Code Review Notes

## Feedback Received

- Read business requirements carefully.
- Decide what one row in the report should represent before writing GROUP BY.
- Use WHERE for row filtering.
- Use HAVING for aggregated values.
- Choose the simplest JOIN that satisfies the business requirement.
- Separate join conditions from filters when using INNER JOIN for readability.
