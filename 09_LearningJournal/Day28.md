## Day 28 Objective

The objective for Day 28 was to assess my actual Excel competency after completing the initial analysis for Portfolio Project #1.

The purpose of this checkpoint was not simply to list the Excel features used in the project. It was to distinguish between:

- Concepts I have actually learned and can use independently.
- Concepts I have encountered and used during the project but still need to practice systematically.
- Concepts that have not yet been formally covered.

This distinction is important because using an Excel feature once during a project does not necessarily mean I have mastered the underlying concept.

---

## Project-First Learning vs. Concept-First Learning

My initial approach to Excel was project-first learning.

Rather than studying Excel concepts systematically before beginning the project, I started working directly on the Ujjsha Financial Technologies retail analysis and learned tools as they became necessary to answer business questions.

For example, I encountered and successfully used:

- XLOOKUP
- Excel Tables
- Structured References
- PivotTables
- Basic calculations
- KPI calculations
- Category analysis
- Product-level analysis
- Revenue analysis
- Month-over-month comparisons

This approach was valuable because I was immediately applying Excel to realistic business questions.

However, the checkpoint identified an important gap:

**Exposure through a project is not the same as systematic learning or mastery.**

For example, I successfully used XLOOKUP in Project #1 and even debugged a product ID data-type mismatch using `VALUE()`. However, I had not yet systematically learned the broader lookup family, including VLOOKUP, HLOOKUP, INDEX, MATCH, XMATCH, exact vs. approximate matching, and more advanced lookup patterns.

The same principle applies to PivotTables and other Excel concepts.

## Revised Excel Learning Approach

Starting with Day 29, Excel learning will become systematic.

The learning process will follow:

**Learn → Example → Solve → Business Scenario → Apply to Ujjsha → Explain Reasoning**

The goal is not simply to memorize Excel functions.

I need to understand:

1. What the function or feature does.
2. Why it is useful.
3. When an analyst would use it.
4. What alternatives exist.
5. What limitations it has.
6. How to troubleshoot it.
7. How to apply it to a real business problem.
8. How to explain the result to a business stakeholder.
